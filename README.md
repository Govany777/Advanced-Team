# ⚜️ منصة مجموعة كشافة المتقدم (Advanced Team)

منصة رقمية متكاملة لمجموعة كشافة مرحلة المتقدم (الكاروزي)، لإدارة الأنشطة والمسابقات الكشفية، تتبع درجات ونقاط الكشافة، نظام الأوسمة والرتب الكشفية، ولوحة تحكم القائد مع ربط كامل بقاعدة بيانات سحابية لحظية (**Firebase Firestore**).

---

## ✨ المميزات الرئيسية

### 1. نظام الحسابات والرتب الكشفية
- إنشاء حسابات الكشافة مع حفظ البيانات (الاسم، كود الكشاف، رقم الهاتف، العنوان، الرتبة الكشفية، والشارة/الرمز المفضل).
- متابعة الرتب الكشفية التلقائية بناءً على النقاط التراكمية.
- سجل إنجازات شخصي لكل كشاف يضم الأوسمة المكتسبة والمهام المنجزة.

### 2. التحديات والمسابقات الكشفية المؤقتة
- مسابقات كشفية متنوعة (اختيار من متعدد، صح أو خطأ، وأسئلة مقالية).
- مؤقت تنازلي حي لكل مسابقة مع تسليم تلقائي عند انتهاء الوقت المحدد.
- تتبع توقيت الحل بدقة بالثواني والدقائق.
- تسجيل الإجابات وتحديد الإجابات الصحيحة والخاطئة مع الإجابة النموذجية المعتمدة.
- لوحة شرف لكل سؤال توضح الأسرع حلاً (🥇 المركز الأول، 🥈 المركز الثاني، 🥉 المركز الثالث...).

### 3. لوحة تحكم القائد (Leader Dashboard)
- محمية بكلمة مرور مخصصة للقادة فقط.
- **إدارة المشاركين**: إضافة وتعديل النقاط (مكافأة أو خصم)، وحذف الأعضاء.
- **إدارة المسابقات**: إضافة مسابقات جديدة، تحديد مواعيد الفتح والإغلاق (الديدلاين)، وتعيين كلمة سر خاصة لكل سؤال عند الحاجة.
- **إدارة المهام اليومية**: إضافة وحذف المهام الكشفية المتجددة.
- **سجل الإجابات والترتيب**: متابعة تفصيلية لترتيب الكشافة حسب أسبقية التسليم وزمن الحل وعرض الإجابات الكاملة لكل كشاف.

### 4. الـ Backend والمزامنة السحابية
- ربط كامل مع **Firebase Firestore** مع قواعد حماية مخصصة.
- مزامنة فورية في الوقت الحقيقي (Real-time sync) عبر جميع الأجهزة.
- دعم العمل دون اتصال (Offline-first) مع التخزين المحلي كطبقة حماية.

---

## 🛠️ التقنيات المستخدمة

- **Framework**: Next.js 16 (App Router & Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Lucide Icons
- **Backend / Database**: Firebase 12 (Cloud Firestore)

---

## 🚀 تشغيل المشروع محلياً

1. استنساخ المستودع:
```bash
git clone https://github.com/Govany777/Advanced-Team.git
cd Advanced-Team
```

2. تثبيت الحزم:
```bash
npm install
```

3. تشغيل خادم التطوير:
```bash
npm run dev
```

4. افتح المتصفح على: [http://localhost:3000](http://localhost:3000)
